# For Bhabhi, with love

A small, responsive birthday experience for Bhabhi, built with React, Vite, Tailwind CSS, Framer Motion, Embla Carousel, and React Three Fiber.

## Run locally

```sh
npm install
npm run dev
```

Create an optimized production build with `npm run build` and preview it with `npm run preview`.

## Experience

- Cinematic birthday landing page with an interactive, lazy-loaded 3D present.
- Birthday note modal, responsive Embla memory carousel, wish-and-candles interaction, and rotating compliments.
- Optional ambient tones generated locally with the Web Audio API; no audio asset or autoplay is required.
- Responsive layouts down to 320px and reduced-motion styling.

The repository was empty when this experience was created, so no pre-existing photos, music, copy, or interactions were available to migrate. The memory cards are original celebratory illustrations and text rather than substituted personal photos. Add personal assets when available.
